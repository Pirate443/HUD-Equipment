--------------------------------------------------------------
			Description:
This mod adds additional settings for equipment slots.
Features of the mod:
- Charge bar for enchanted weapons. The code is taken from the mod "HUD Weapon Charge" by Virnetch and modified so that the slot does not shift vertically when switching between enchanted and ordinary weapons.
- The size of the magic slot has been adjusted for convenient configuration via "HUD Customizer" by Sephumbra - now you can set the same vertical values for the weapon and magic slots and they will always be on the same line.
- The color of the magic slot charge bar can be switched to blue to match other magic indicators.
- Slot size adjustment.
- Slot background opacity adjustment.
- Show/hide the background for enchanted item icons.
- Show/hide and adjust the position of effect icons for enchanted items.
